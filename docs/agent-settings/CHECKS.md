## Roles

- **Builds:** A Claude agent session.
- **Reviews:** The builder reviews its own work. An independent review happens when the owner asks.
- **Merges:** On the owner's instruction.

## The check command

```sh
npm test -- --ci --maxWorkers=2
```

Hosted CI: Yes: GitHub Actions (Jest, end-to-end funnel, claim boundary, package and readiness guards, Anchor program tests).

## What each check needs

"Cloud session" means a cloud agent session with no machine linked to it. A check that
cannot run there is a stop for that session, not a pass: say so in the pull request and
name the machine that has to run it.

| Check | Command | Needs | Runs in a cloud session |
|---|---|---|---|
| Jest | `npm test -- --ci --maxWorkers=2` | Node (see .mise.toml), npm ci | not tried |
| Node script tests | `node --test scripts/__tests__/<file>.test.mjs` | Node | yes |
| End-to-end funnel | `npm run test:e2e` | Playwright with Chromium; starts its own dev server | not tried; the hosted job failed once and passed on a re-run on 11 November 2026 |
| Public claim boundary | `npm run check:claims:public` | Node | not tried |
| Anchor program build and tests | `cargo test -p escrow` | the pinned Solana and Anchor toolchain (docs/SOLANA-TOOLCHAIN-BASELINE.md) | no |
| Devnet, Surfpool and browser-wallet scripts | inspect before running | owner approval; some spend devnet SOL or use live RPC | no |
