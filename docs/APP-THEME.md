# App theme

The developer app (repo root) uses the marketing site's paper-and-ink look
(`apps/marketing/app/globals.css`), so the two addresses read as one product.
Owner decision, 21 November 2026: light paper is the default; dark follows the
operating system setting, and people can pin Light or Dark themselves.

## Choosing a theme

`components/ThemeToggle.tsx` in the header cycles Auto, Light and Dark. Auto
(no `data-theme` on `<html>`) follows `prefers-color-scheme`, so the app goes
dark when the system does. Light or Dark sets `data-theme` and is saved in
`localStorage` under `rap-theme`; the inline script in `app/layout.tsx` applies
it before first paint, so there is no flash.

## Where it lives

- `app/globals.css`: the semantic tokens (`--paper`, `--paper-raised`, `--well`,
  `--ink`, `--ink-muted`, `--line`, `--line-strong`, `--brand-green`,
  `--brand-violet`) with their light values on `:root` and dark values under
  `prefers-color-scheme: dark` and `:root[data-theme="dark"]`. They are exposed
  to Tailwind as `bg-paper`, `text-ink`, `border-line`, `text-brand-green` and so
  on, and the shadcn variables (`--background`, `--primary`, ...) point at them.
- `app/legacy-palette.css`: generated by
  `python3 scripts/ux/generate-legacy-palette.py node_modules/tailwindcss/theme.css > app/legacy-palette.css`.
  The pages were written for a dark background with Tailwind palette classes
  (`text-white`, `text-gray-400`, `bg-white/5`, `text-indigo-300` ...). In the
  light theme this file remaps those palette variables to their light-ground
  counterparts (white becomes ink, black becomes paper, each colour scale is
  flipped), so every page follows the theme without rewriting each class. In
  the dark theme it restores Tailwind's own values. Do not edit it by hand.

## Rules for new and reworked code

- Use the semantic classes (`bg-paper-raised`, `text-ink`, `text-ink-muted`,
  `border-line`, `bg-ink text-paper` for the one primary button) rather than
  palette classes. Palette classes still work, but they are the transition
  layer; pages move off them as they are reworked.
- One primary action per view: `bg-ink text-paper`. Secondary actions are
  outlined (`border-2 border-ink`). No gradient buttons, glows or emoji icons.
- Text meets 4.5:1 in both themes. Check with an axe scan in light and dark
  (`colorScheme: "dark"` in Playwright) before merging a UI change.
- Underline links that sit inside running text; the base layer does this for
  `p a`, `li a`, `dd a` and `td a`.
